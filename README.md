# Code-Sync

A real-time collaborative code editor that allows multiple users to write, edit, and collaborate on code in the same workspace.

## 🚀 Features

- 💻 Real-time collaborative code editing
- 📁 Create, edit, save, delete, and organize files
- 💾 Download the complete codebase as a ZIP file
- 🔗 Create and join coding rooms using a unique Room ID
- 🌍 Support for multiple programming languages
- 🌈 Syntax highlighting and automatic language detection
- ▶️ Execute code directly from the editor
- ⚡ Real-time synchronization of code changes
- 👥 Online user presence
- 📣 Join and leave notifications
- 💬 Real-time group chat
- 🖱️ Real-time cursor and text selection sharing
- 💡 Programming language-based suggestions
- 🔠 Custom font size and font family
- 🎨 Multiple editor themes
- 🖌️ Real-time collaborative drawing
- 🤖 AI-powered code generation

## 🤖 AI Code Generation

The application includes an AI-powered coding assistant that can:

- Generate code from natural-language prompts
- Insert generated code into the editor
- Copy generated code
- Replace existing code
- Assist users while working inside the collaborative editor
